# 🍞 The Daily Crumb | Gourmet Recipe Blog

**The Daily Crumb** is a sleek, responsive, and beautifully designed gourmet recipe blog website built with semantic HTML5 and modern CSS3. It features a curated collection of quick weekday meals, delectable desserts, healthy salads, and comforting breakfast ideas.

## ✨ Features

* **Responsive Layout:** Optimized to provide a seamless viewing experience across mobile devices, tablets, and desktop screens.
* **Featured Recipe Hero Section:** Highlights a standout dish (e.g., Vibrant Berry Smoothie Bowl) with quick prep times and clean imagery.
* **Recipe Grid:** Showcases diverse categories including Main Courses, Desserts, Healthy Meals, and Breakfast.
* **Author Widget ("Meet Sarah"):** Personalizes the blog with a dedicated creator section.
* **Newsletter Subscription Form:** Clean layout for visitors to sign up for weekly recipe updates.
* **Modern CSS Styling:** Utilizes CSS Grid, Flexbox, custom variables, and a cohesive forest green color palette (`#2e5a44`).

## 🛠️ Built With

* **HTML5:** Semantic markup structure (`header`, `main`, `section`, `article`, `aside`, `footer`).
* **CSS3:** Custom properties/variables, Flexbox, and CSS Grid layouts with media queries for responsiveness.
* **FontAwesome:** Icons utilized for social media links and navigation styling.
